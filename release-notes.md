# Anchor Recall 0.1.0 — тестовая сборка

Зафиксированная сборка: `friend-beta-2026-11-09-d01a05ced0d4`.
Для настольного Obsidian 1.13.7 или новее.

Карточки активного вспоминания, независимая практика Банка, расписание Core,
точные переходы к своим источникам и необязательные интеграции с Telegram
Mini App и Google Calendar.

Последний завершённый этап — сохранение ответов с явным выбором пользователя,
их просмотр, перенос с резервными копиями и удаление без изменения оценок
или расписания. Существующие данные v1 сохраняются.

Проверки: финальный `pnpm verify` успешен; 7 599 успешных тестов в основном
наборе, 6 пропущены. Пройдены отдельные проверки лицензий, FSRS/WASM,
сборки Telegram и 162 синтетические проверки интерфейса. Живая установка
этой сборки в чистое хранилище ещё ожидает проверки тестировщиком.

## Установка для команды

В BRAT добавьте `GregoryTelegin/anchor-recall-beta` и выберите версию **0.1.0**.
Для публичного репозитория сборок токен GitHub не нужен. Обновления выпускаются отдельно.

При ручной установке используйте ZIP с инструкцией `TESTER-ru.md`.
Локальные занятия работают без Google Calendar, Telegram и аккаунтов этих
сервисов. Их подключение и передача выбранных материалов требуют отдельного
доступа и явного согласия пользователя.

Данные автора, карточки, прогресс, токены и настройки личных подключений
в файлы релиза не входят. Исходные заметки и медиа не входят в JSON-копию
библиотеки: резервируйте своё хранилище целиком отдельно.

К релизу GitHub необходимо прикрепить **отдельными файлами**:
`main.js`, `manifest.json`, `styles.css`. Один ZIP не заменяет эти assets для BRAT.

лицензиях сохраняются в соответствии с действующей лицензией проекта.
